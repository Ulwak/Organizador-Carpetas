# Organizador-Carpetas
Organizador de archivos para cualquier carpeta.

Nacio de la pereza de organizar los archivos manualmente en subcarpetas.

Es un script basico de 3 funciones que clasifica obteniendo las extensiones de los archivos y agrupandolos en carpetas. Tambien clasifica archivos ocultos aunque se le pregunta al usuario si desea clasificarlos.
